# Modelo – Matriz Gerencial

Abra `index.html` no navegador (não precisa de servidor).

- `index.html`  estrutura (capa, sidebar, 5 páginas, busca)
- `styles.css`  tokens, grid/flex, organograma, responsivo
- `data.js`     ETAPAS e GRUPOS: edite aqui o conteúdo
- `app.js`      roteador por hash, renderização, busca
- `assets/`     troque `matriz-placeholder.svg` pela sua imagem

Para novos hotspots: porcentagens left/top/width/height (centro da caixa ÷ tamanho da imagem).
